# DEC●PO（デコポ）

DEC●POは、iPhone
SEクラスの小さな画面での操作を前提に設計した、単一HTMLファイルで動作するスタンドアロン型シーケンサーです。

HTML5 / JavaScriptとWeb Audio APIで構成し、App
Storeや外部サービス、外部音源ライブラリに依存せず、ローカル環境でも動作します。レコンポーザに代表される数値入力型シーケンサーの操作思想を参考にしつつ、スマートフォンで扱いやすい形へ再設計しています。

## 主な特徴

### 1. スマートフォン向けの入力設計

**ROLLモード**\
縦画面でピアノロールを操作します。右端付近までスクロールすると、1小節（16ステップ）ずつ編集領域を追加します。

**ST/GTモード**\
ST（ステップタイム）、GT（ゲートタイム）、VEL（ベロシティ）を数値で編集します。数値入力欄には
`inputmode="numeric"`
を使用し、スマートフォンでテンキーを呼び出しやすくしています。

### 2. 単一HTML・外部依存なし

外部のサンプリング音源やJavaScriptライブラリを使用せず、Web Audio
APIによる波形合成で発音します。

HTMLファイル単体で保存・実行できるため、ネット接続のない環境でも使用できます。

### 3. MIDI / JSONへの保存

入力したデータはJSON形式で保存できます。

また、可変長数量（VLQ）の処理を含むSMF書き出し機能を内蔵し、標準MIDIファイル（`.mid`）として出力できます。

## 8bit版の音源構成

-   TK1：矩形波
-   TK2：矩形波
-   TK3：三角波
-   TK4：正弦波
-   DRM：ノイズドラム（BD / SD / CH / OH）

------------------------------------------------------------------------

## 開発方針

8bit版と標準MIDI版は、目的の異なるブランチとして管理します。

8bit版は軽量な内蔵音源とスマートフォンでの操作性を中心とし、標準MIDI版ではタイムベース96、和音入力、16チャンネル化など、より一般的なMIDIシーケンサーとしての機能を扱います。
